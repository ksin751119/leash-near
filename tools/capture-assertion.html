Leash passkey capture

Registers a passkey on this device and produces one assertion, printed in exactly the JSON shape of tests-sandbox/tests/fixtures/*.json, so a real capture is a drop-in replacement for a generated fixture.

Before you start

  1. WebAuthn needs a secure context. Serve this file over HTTPS, or open it on http://localhost. A file:// URL will not work.
  2. To capture from a phone, put the page behind an HTTPS tunnel and open the tunnel's URL on the phone. The rpId below has to be that hostname or a parent of it.
  3. Register, then assert. The browser will ask for Face ID, a fingerprint or the device PIN; that unlock is what sets the UV bit the contract checks.
